プライバシーポリシー

最終更新: 2026年11月6日

「Tsukumo」(以下「本アプリ」)は、個人が自宅で使う生活サポート AI です。本ポリシーは、本アプリが取り扱うデータとその利用目的を説明します。

1. 取得するデータ

  • Google カレンダーの予定(件名・日時・場所など): 利用者が Google アカウントの連携に同意した場合にのみ、読み取ります。
  • Google Tasks のタスク(件名・期限・状態): 同じく、同意した場合にのみ、読み取ります。
  • 利用者が本アプリに話しかけた内容(音声・LINE のメッセージ): 応答のために処理します。

2. 利用目的

取得したデータは、「今日の予定は」「このタスクを完了にして」といった、利用者本人からの依頼に応えるためにのみ使います。広告、第三者への販売、プロファイリングには使用しません。

3. Google ユーザーデータの取り扱い(Limited Use)

本アプリによる Google API から受け取った情報の使用および他のアプリへの移転は、Google API サービスのユーザーデータに関するポリシー(Limited Use の要件を含む)に準拠します。具体的には次のとおりです。

  • Google のデータは、利用者に提示される機能の提供のためにのみ使用します。
  • 法令の遵守、セキュリティ上の目的、または利用者の同意がある場合を除き、第三者に提供・移転しません。
  • 広告の配信(パーソナライズ広告を含む)には使用しません。
  • 人間が閲覧することはありません(利用者本人の同意、セキュリティ調査、法令の遵守のための場合を除く)。

4. 書き込みについて

予定やタスクの追加・変更・削除・完了は、利用者の承認を得てから行います。ただし、利用者が言った内容と同じ範囲の、期限の小さな変更に限り、確認を省くことがあります。

5. 保存と保護

  • 読み取った予定・タスクの内容は、本アプリのデータ置き場には保存しません。応答に使うその場でのみ扱います。
  • Google との連携に使う認証情報(リフレッシュトークン)は、利用者本人が管理するコンピューターの環境変数にのみ保存し、ソースコードや公開の場所には置きません。
  • 通信は HTTPS で保護します。本アプリは、許可された利用者のみが使えます。

6. 外部サービスへの送信

  • Google API(Calendar / Tasks): データの読み取りと書き込みのため。
  • AI による応答の生成のため、依頼の文面と、依頼に答えるために必要な範囲の予定・タスクの情報を、Anthropic の API(Claude)に送ることがあります。送った内容は、本アプリでは保存しません。
  • LINE(LINE Messaging API): LINE での応答の送受信のため。

7. 連携の解除とデータの削除

Google との連携は、Google アカウントの権限設定からいつでも解除できます。解除すると、本アプリは以降、Google のデータにアクセスできなくなります。本アプリが保存しているデータの削除を希望する場合は、下記までご連絡ください。

8. 改定

本ポリシーを変更する場合は、本ページで告知します。

9. お問い合わせ

GitHub の Issuesからご連絡ください。
